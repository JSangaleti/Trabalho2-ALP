## Objetivo

O objetivo deste trabalho é desenvolver duas aplicações utilizando conceitos de programação funcional, explorando recursos como funções puras, funções de ordem superior, funções anônimas (lambda), recursão, composição de funções, operações sobre listas e estruturas de dados imutáveis.

O trabalho busca proporcionar uma experiência prática com os conceitos estudados na disciplina, permitindo compreender como o paradigma funcional pode ser utilizado na resolução de problemas computacionais.

## Requisitos de programação funcional

As duas aplicações deverão ser desenvolvidas utilizando construções e conceitos de programação funcional.

O grupo deverá demonstrar a utilização de pelo menos cinco dos seguintes recursos, considerando o conjunto das duas aplicações:

- Funções anônimas (lambda): definição de funções sem a necessidade de atribuir nomes a elas.
- Funções de ordem superior: funções que recebem outras funções como
parâmetros ou retornam funções.
- Map: aplicação de uma função a todos os elementos de uma coleção;
- Filter: seleção de elementos de uma coleção a partir de um critério;
- Fold (foldl/foldr/reduce): redução de uma coleção a um único resultado por meio de uma função;
- Composição de funções: combinação de funções menores para construir operações mais complexas;
- Recursão: utilização de chamadas recursivas para resolver problemas, em substituição ou complemento a estruturas de repetição;
- Imutabilidade e funções puras: evitar alterações de estado compartilhado e priorizar funções cujo resultado depende apenas de seus argumentos;
- List comprehensions: construção de listas a partir de expressões e condições, quando disponível na linguagem;
- Avaliação preguiçosa (lazy evaluation): quando suportada pela linguagem, demonstrar como a avaliação sob demanda pode ser utilizada.

Os recursos deverão ser efetivamente utilizados na implementação, e não apenas mencionados na documentação.

O grupo deverá identificar, no código-fonte e no README, onde os conceitos funcionais foram aplicados e explicar sua contribuição para a solução dos problemas.

## Linguagem e ferramentas

A linguagem escolhida foi **Python**, pelo equilíbrio entre facilidade de implementação e clareza para explicar o código na apresentação.
